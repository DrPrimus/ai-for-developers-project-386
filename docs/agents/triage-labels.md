# Метки триажа

Скилы говорят о пяти канонических ролях триажа. Этот файл сопоставляет роли с реальными строками меток в трекере репозитория.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение                                     |
| ------------------------ | --------------------- | -------------------------------------------- |
| `needs-triage`           | `needs-triage`        | Мейнтейнеру нужно оценить issue              |
| `needs-info`             | `needs-info`          | Ждём от автора дополнительной информации     |
| `ready-for-agent`        | `ready-for-agent`     | Полностью специфицировано, готово для AFK-агента |
| `ready-for-human`        | `ready-for-human`     | Требует реализации человеком                 |
| `wontfix`                | `wontfix`             | Не будет сделано                             |

Когда скил упоминает роль (например, «поставь метку AFK-ready»), используйте соответствующую строку из таблицы.

Редактируйте колонку «Метка в нашем трекере», если словарь изменится.
