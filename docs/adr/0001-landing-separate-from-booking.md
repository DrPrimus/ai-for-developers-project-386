# Главная страница — витрина сервиса, запись — на отдельном маршруте

Гость попадает на главную страницу с описанием сервиса и кнопкой «Записаться», а бронирование живёт на `/booking`. Исходный README предполагал, что гость сразу видит типы встреч, но проекту нужна витрина с двумя точками входа — гостевой и владельческой. Компромисс: гость делает один лишний клик, зато у сервиса появляется публичная главная и единый хедер; README обновлён под это поведение.

Статус: accepted.
